# Security Policy

## Supported Versions

No versions of this project are
currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

This web application is intentionally vulnerable, but any other vulnerability that is found which is outside the scope of the documentation published with the project, report the same through the contact details given in the code of conduct documentation. While reporting include solutions, evidences and other required details regarding the scenario of the vulnerability.
